# Spaced Repetition (Medical SRS) — AI Context File
_Last synced: 2026-06-10 @ f54dfe3_

## 1. What This Is (Plain English)
- **In one sentence:** A learning system holding the **entire FMPM medical curriculum (S1→S10, ~1310 lessons)** that tells you which lessons to review today, shows your progress in charts, and (online) syncs reviews to Google Calendar.
- **Why it exists:** ~1310 lessons can't be tracked by hand. You log *when* you studied and *how well you recalled* (0–5); the system schedules the next review and **recovers gracefully** when you miss days.
- **Who uses it:** Just the owner — a med student. Personal tool, but their real study schedule and **real study progress live in the sheet** (see §6).
- **Vibe:** Polished personal tool. **Three things working together:** the spreadsheet, the Apps Script, and a Python generator that rebuilds the spreadsheet.

## 2. How To Run It
No build, no npm. Two ways to *use*, one way to *rebuild*.

### Online (full power — Google Sheets)
1. Upload **`srs-system.xlsx`** to Drive, open as a Google Sheet.
2. **Extensions → Apps Script**, paste all of **`srs-appscript.js`**, save, run `setupTriggers()` once.
3. Optional but great — palette shortcut: **Extensions → Macros → Import macro → `openCommandPalette` → assign number 1** ⇒ **Ctrl+Alt+Shift+1** opens the command palette (Sheets reserves real Ctrl+K; inside the palette Ctrl+K refocuses search).

### Offline (Microsoft Excel)
- Open `srs-system.xlsx` directly. All formulas/tabs work; **no calendar sync, no palette** (Apps Script is Google-only). The `FILTER`-based lists (Today queue, Module View) need **Excel 365**; on older Excel they show a fallback message — use the row-2 ▼ filters instead.

### Daily use
Open the **Today** tab → study the queue top-down → per lesson type **F = Last Review** (Ctrl+;) and **G = Mastery 0–5** on `lesson-database` (or online: palette → type lesson → Enter → press 0–5). `N = Notes` is optional.

### Rebuild / extend
```
python3 scripts/build_srs_xlsx.py     # repo root; needs: pip install openpyxl
```
Edit `data/curriculum_FMPM_S1-S10.txt`, re-run. **Preserves:** progress + notes (matched on `Semester|Module|Lesson`), the History log, and the exam date (`Dashboard!J3`).

- **Required env vars:** None.

## 3. Tech Stack
- **Spreadsheet** — generated by openpyxl; formulas only (`IF/TODAY/COUNTIF(S)/COUNTA/INDEX/MATCH/FILTER/SORT/UNIQUE`) chosen to work in both Excel and Sheets (FILTER/SORT/UNIQUE = 365/Sheets, with fallbacks).
- **Google Apps Script (V8)** — `srs-appscript.js`, single file (the palette HTML is an inline template string — keeps setup "paste one file"). Uses `SpreadsheetApp`, `CalendarApp`, `ScriptApp`, `HtmlService`, `Utilities`.
- **Python 3 + openpyxl** — `scripts/build_srs_xlsx.py`, the generator.
- **External services:** Google Sheets + Google Calendar (default calendar), online only.

## 4. Code Map (The Important Files Only)
- `srs-appscript.js` — online engine: `syncToCalendar`, `smartReschedule`, `showDailyDigest`, **`openCommandPalette`/`getPaletteData`/`paletteCommand`** (sidebar), **`filterModuleFromPalette`/`clearModuleFilter`** (set the real sheet filter), **`reviewLessonFromPalette`** (F=today, G=mastery in one call), **`logDailySnapshot`** (daily 22:00 → History), triggers, menu. `PALETTE_HTML_` at the bottom is the sidebar UI.
- `srs-system.xlsx` — 7 sheets:
  - **`Today`** ⚡ (landing tab) — due-now queue (sorted, most overdue first) + **cheat sheet** (mastery table, golden rules, shortcuts).
  - **`Dashboard`** 📊 macro/bird's-eye — KPIs, **exam countdown (input `J3`)**, per-semester & per-module tables, **5 charts** (incl. progress-over-time from History).
  - **`lesson-database`** — the engine; rows 3–1312; the only sheet you type in (F, G, optional N=Notes). AutoFilter on row 2.
  - **`Module View`** 🔍 micro — dropdown → stats, **per-subject breakdown**, mastery chart, lesson list.
  - **`Weekly`** — 7-day workload. **`How-To`** — guide. **`History`** — script-managed daily snapshots; **do not hand-edit**.
- `scripts/build_srs_xlsx.py` — the generator. **Change structure/visuals here, then re-run** — never hand-edit the binary for structure.
- `data/curriculum_FMPM_S1-S10.txt` — single source of truth for lessons (per-semester files are identical slices).
- `backups/simple system/` — **READ-ONLY**, older variant, different column layout. `spaced repetition old/`, `ai-report.txt` — history.

### Column map — `lesson-database`, data from row 3 (MUST match `CONFIG.COL` in the JS)
`A` # · `B` Semester · `C` Module · `D` Subject · `E` Lesson · `F` **Last Review (input)** · `G` **Mastery 0–5 (input)** · `H` Interval · `I` Next Review · `J` Status · `K` Priority · `L` Synced · `M` Event ID (hidden) · `N` Notes (optional input; script ignores).

### The core SRS rule (lives in TWO places — keep identical)
Mastery → days: **0→1, 1→3, 2→7, 3→14, 4→30, 5→done**.
- Sheet: column-H formula. — JS: `const INTERVALS = [1,3,7,14,30,60]` (used by `smartReschedule` and `reviewLessonFromPalette`).
- `I = F + H`. Calendar title: `📚 s3 - Sémiologie I | Diarrhée aiguë` (`buildTitle_`).

### Legends
- **Status (J):** `⚪ NEW` · `✅ DONE` · `🔴 OVERDUE` · `🟢 TODAY` · `🔵 TOMORROW` · `📅 THIS WEEK` · `⏳ SCHEDULED`.
- **Priority (K):** days until due (negative = overdue); `999` new, `9999` mastered. The Today queue = rows where `K ≤ 0`.

## 5. Rules For Editing This Code
- **Interval rule in BOTH files or neither** (sheet col-H formula ⇄ JS `INTERVALS`). #1 rule.
- **Column positions are load-bearing** — the script reads by index. Reorder ⇒ update `CONFIG.COL` + `onEditTrigger` (watches F/G).
- **Structure changes go through the generator**, then re-run it. It must keep preserving: progress/notes (by `Semester|Module|Lesson`), History rows, exam date `Dashboard!J3`.
- **Keep formulas cross-compatible** (Excel + Sheets). FILTER/SORT/UNIQUE only with `IFERROR` fallbacks.
- **Apps Script stays ONE file** — the palette HTML lives in the `PALETTE_HTML_` template string; don't split it out.
- **Menu/`google.script.run` functions must NOT end in `_`** (Apps Script treats those as private — they fail from menus/sidebar). Trailing-`_` is reserved for internal helpers.
- **`backups/` is read-only.** **`History` sheet is script-managed** — never hand-edit or "clean" it.
- `HEADER_ROWS = 2`; data starts row 3. You only type in F, G, N.

## 6. Fragile Bits & Landmines
- **Real study progress lives in the sheet** (7 S8 lessons, Feb–Mar 2026, plus whatever the owner adds). The generator preserves it **only while names match** — renaming a module/lesson in `data/` orphans its progress on regenerate (recoverable via git).
- **`smartReschedule` back-dates Last Review** (`target − INTERVALS[mastery]`) so `I = F + H` lands on the target day. Changing `INTERVALS` silently breaks it.
- **`onEditTrigger` sleeps 1500 ms on purpose** (lets I/J recalc before sync reads them) and only fires on F/G edits.
- **`reviewLessonFromPalette` does NOT sync the calendar immediately** — the hourly trigger (or palette "Sync now") catches up. Don't "fix" this; per-review full syncs are slow.
- **Palette macro shortcut can only be a digit** — Sheets macros allow `Ctrl+Alt+Shift+0–9` only; real Ctrl+K cannot be rebound. Documented in How-To; don't promise otherwise.
- **`parseDate_` rejects years <2025 or >2100** (junk guard); out-of-range date ⇒ treated as no date ⇒ event deleted.
- **Formula ranges bound to `$3:$2000`**; Today/Module View spill formatting & CF pre-applied to row 600. Curriculum >2000 lessons ⇒ bump `LAST` in the generator.
- **Dashboard fixed rows:** semester table 14–23, module table 46–89, History chart reads `History!A1:E400` (~1 year of snapshots; widen `max_row` after that). Don't hand-insert rows on Dashboard.
- **The simple backup's column layout is incompatible** — never copy its `CONFIG`.
- **LibreOffice headless can't open xlsx in this container** (env quirk). Validate via openpyxl reload + the `formulas` lib on small samples (note: that lib mis-evaluates `"<>"` non-blank criteria; real Excel/Sheets are fine).
